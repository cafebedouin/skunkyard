# skunkyard

Research arm for Ergo: questions about the protocol that only measurement on Ergo's own chain and script language can
answer. First program: post-quantum readiness, measured (`SCOPE.md`); pilot: a Winternitz verifier in ErgoScript
(`PILOT-Q2.md`).

Sibling project: peeryard (network test bench). Prepared with Claude (Anthropic).

Results and measurements for Q2 pilot: see [`q2/README.md`](q2/README.md).

Second program: TSNP, the Temporal Stealth Note Protocol specification posted to the forum in March 2026, with the
pilot that would answer its open items and a note on its terms against the quantum horizon (`tsnp/`).
