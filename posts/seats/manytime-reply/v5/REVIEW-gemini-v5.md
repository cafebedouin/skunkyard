   - **Cryptographic precision on the one-time rule and off-chain exposure:** From a cryptographic perspective, publishing a single signature on leaf $k+1$ for an unconfirmed replacement does not immediately allow an attacker to forge a transaction spending the newly confirmed singleton box at index $k+1$, because the confirmed singleton has a different box ID (`inBytes` covers all input IDs). It is this second signature on a distinct message that collapses WOTS security and opens the forgery window. The text compresses this mechanism; explicitly distinguishing between the off-chain leakage of the first signature and the restored wallet's danger of issuing a second signature on the same leaf makes the cryptographic threat model watertight.
