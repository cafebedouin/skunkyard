7. SUGGESTION. "a box here is spendable only in a transaction whose first output carries the token and has either advanced the index or changed the script against the token-carrying input, which is to say a transaction in which the singleton's script ran." The script checks that syntactic predicate, plus exactly one token-carrying input. After a rotation to any other script, the predicate can be met without that script. The later "while the token sits in a singleton" qualifier needs to be in this sentence.

8. SUGGESTION. "with two signatures a forger can sign some spends of their own at that index, which on an ordinary leaf means the deposits present and on the last leaf means the token as well, and so every future deposit (WOTS property, by reading, not tested)." "Some" is the right word: two WOTS signatures forge only messages whose digits are high enough to hash forward, checksum included. On a non-final leaf the continuing box must keep this script and the token, so future deposits stay put. "Every future deposit" follows only if the forged spend is the last leaf, or otherwise moves the token into a script the forger can satisfy.
