Prepared with Claude Code (Anthropic, Claude Fable 5.1) for cafebedouin using peeryard v0.1.0 (ba56b25) on 6.0.6 (21b9023933b1); executed on a devnet, recorded in the skunkyard project.

Section 5 listed the many-time construction as unimplemented. It is implemented and run (skunkyard, `skunks/manytime/`).

A box commits to 16 WOTS keys as an AVL digest in its script (33 bytes at any count) and carries the next leaf index in R4. A spend supplies the leaf's signature and lookup proof, and until the final leaf must recreate the box with the index advanced; the verifier is section 2's, with the commitment read from the tree. On a devnet (ergo 6.0.6, block version 4): a forged signature rejected; a spend leaving the index unchanged rejected at 38 cost units, since the state check runs first; leaf 0 replayed against the box reading index 1 rejected, the lookup failing for the key the script computes (an evaluation exception, so the node reports no cost for it); two consecutive spends confirmed with the index reading 1, then 2.

Per spend: 37,860 cost units against 37,592 for the one-time box, 3,450 bytes against 2,345 (the recreated 953-byte box rides along with the signature and proof); per mainnet block, 156 by cost and 368 by size, against 154 and 542. The chain enforces the index on every spend but the last; the wallet keeps one rule, never sign a leaf twice: a stuck spend is replaced by spending the output, since the index advances only on confirmation. Not shown: hiding which leaf signed (R4 and the proof name it; the unused commitments stay inside the digest); binding of other inputs (the message covers SELF.id and the outputs, as in section 2); adding leaves (the tree is built off chain and read-only). A used leaf's signature and proof reveal that leaf's public key and the sibling hashes along its path, nothing about unused leaves.

Two notes on the summary above, for a reader checking it against the tables. The capacity line, "about 154 against 596, 3.9x", is the cost bound for one input; the size bound in section 3's table is 542 against 4,367, and a native opcode does not move it, since the signature stays in the transaction. Storage rent falls on a box unspent for 1,051,200 blocks: an 866-byte WOTS box reaching that age pays about 1.08 ERG per period at today's factor, against about 0.13 for a P2PK box, and the census's oldest exposed bucket (older than 525,600 blocks at height 753,934: 9.16M ERG in 29,795 boxes, `q1/RESULT.md`) is the cohort that reaches that age first. "Nothing to do today" in section 6 is about action, not about what a lock costs to hold.
